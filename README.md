# Démos sites web

Sites de démonstration réalisés par Wajih Jemli (consultant IA & relation client, Nabeul, Tunisie).

Chaque site est rangé dans son propre dossier et publié avec GitHub Pages :
`https://wajihjemli.github.io/demos-sites-web/<dossier>/`

Les entreprises présentées dans ces démos sont **fictives** et signalées comme telles sur chaque site.

## Sites

| Dossier | Description | État |
|---|---|---|
| `site-vitrine/` | Boutique fictive d'art de la table à Nabeul : site vitrine adapté au mobile, formulaire de contact (démo, sans envoi) et assistant FAQ par mots-clés | En ligne |

## Outils

- HTML, CSS et JavaScript, sans framework ni étape de compilation.
- Hébergement : GitHub Pages (ou chez l'hébergeur du client pour les projets réels).

## Voir un site en local

```bash
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000/`.
